# AWUKU

**AI Research · Agent Systems**

AWUKU is focused on the research and engineering of intelligent software systems, with an emphasis on AI agents, autonomous workflows, orchestration, evaluation, and reusable infrastructure.

---

### Areas of work

* AI agent architectures
* Multi-agent and orchestration systems
* Autonomous software workflows
* Agent evaluation and reliability
* Developer tooling and infrastructure
* Reusable rules, skills, and operational patterns
